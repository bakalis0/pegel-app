# Pegel – bar stock control (test version 0.1)

Installable web app (PWA). Open the address on your phone, then:
- iPhone: Safari › Share › Add to Home Screen
- Android: Chrome › menu › Install app

Works offline after the first visit. Data stays on the phone; use Setup › Download backup.

Files: index.html (the whole app), sw.js (offline), manifest.webmanifest and icons.
